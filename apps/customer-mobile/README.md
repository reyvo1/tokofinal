# Toko360 Customer Mobile

Starter Flutter untuk aplikasi pelanggan. Aplikasi membaca `/platform/manifest` agar menu dan kemampuan mengikuti feature flag perusahaan, kemudian menggunakan endpoint katalog/order/payment/tracking yang sama dengan storefront.

Sebelum production tambahkan secure storage, auth/refresh token, state management, routing, push notification, deep link payment, offline cache, tests, dan store signing.
