# Architecture Decision Records

Gunakan ADR untuk keputusan yang memengaruhi lebih dari satu modul, kontrak API, database, accounting-tax, sinkronisasi, keamanan, atau deployment.

Nama file:

```text
NNNN-judul-keputusan.md
```

Struktur:

```markdown
# Judul
Status: Proposed | Accepted | Superseded | Rejected
Date: YYYY-MM-DD
Work item: T360-...

## Context
## Decision
## Consequences
## Migration and rollback
## Security and operational impact
```
